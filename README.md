# Dravyaguna World

A plant-first, world-class learning and reference platform for BAMS/Dravyaguna students.

## Project principles
- Plant-only scope.
- Source-grounded academic content.
- Clear separation of classical claims, modern evidence, and unverified data.
- Structured plant identity, taxonomy, morphology, parts, properties, uses, formulations, references, and media.
- Mobile-first, fast, accessible, searchable, and maintainable.
- Data quality and image verification are first-class features.
- Low-cost/free infrastructure where practical.
- GitHub is the project source of truth.
