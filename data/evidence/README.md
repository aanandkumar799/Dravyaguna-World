# Evidence matrix

This directory is reserved for claim-level evidence mappings. A mapping must identify the plant, target claim category, source ID, and review state. Evidence is not considered verified until a reviewer confirms that the cited source supports the exact claim.

Current taxonomic seed review uses Kew POWO/WCVP as an authoritative taxonomic reference where applicable.
