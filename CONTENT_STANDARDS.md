# Academic & Content Standards

## Required plant identity
- Stable internal ID
- Accepted botanical/scientific name
- Family
- Sanskrit/classical names
- Common names
- Synonyms where verified
- Taxonomic status where relevant

## Plant study fields
- Habit
- Morphology
- Root/stem/bark/leaf/flower/fruit/seed/whole-plant characteristics as applicable
- Habitat and distribution
- Identifying/distinguishing features
- Useful parts
- Rasa
- Guna
- Virya
- Vipaka
- Karma
- Dosha effects
- Therapeutic uses/indications
- Formulations
- Contraindications/cautions only when adequately sourced
- Classical references
- Modern scientific evidence where appropriate

## Source policy
Each significant claim should have source metadata:
- source title
- author/institution
- edition/year when available
- page/section/identifier where available
- URL/DOI when applicable
- verification state

Classical and modern evidence must remain distinguishable.

## Uncertainty
If identity, claim, translation, or source is uncertain, mark it as unverified rather than guessing.
